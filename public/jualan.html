04 · Cara Pakai
Cara pakai

Cuma 3 langkah, 15 detik

Tidak perlu paham printer atau driver apapun.

1

Hubungkan printer

Nyalakan printer thermal Bluetooth, klik Hubungkan Printer, pilih nama printer di dialog browser. Besok-besok tersambung sendiri.

2

Masukkan resi

Unggah file PDF resi dari aplikasi marketplace, atau buka tab Input Manual dan isi data pesanan.

3

Print

Pilih lebar kertas (58/72/80mm), tentukan rangkap & ruang gunting, klik Print. Resi keluar, tinggal tempel.

09 · FAQ
Sering ditanya

FAQ sebelum beli

🤔 Butuh printer khusus?

Tidak. Printer thermal Bluetooth apa pun yang sudah Anda punya — cek dulu di daftar kompatibilitas.

📱 Harus install?

Tidak. Buka link di Chrome, langsung bisa. Bisa juga ditambahkan ke layar utama (PWA) biar seperti aplikasi.

🔑 Dapat kode akses?

Ya. Setelah pembayaran Anda terima 1 kode unik. Masukkan sekali, setelah itu terbuka terus di perangkat itu — beli sekali, pakai selamanya.

🍎 iPhone bisa?

Bisa pakai browser Bluefy (Chrome iOS belum mendukung Bluetooth cetak).

⚡ Resi terpotong?

Ganti pilihan lebar kertas (58 / 72 / 80mm). Panduan lengkap ada di menu "Cara Pakai" dalam aplikasi.

🔒 Data aman?

File resi tidak pernah diunggah ke server — semua diproses di perangkat Anda sendiri.
