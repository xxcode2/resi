3. Upload resi (PDF/PNG/JPG) atau pakai tab Input Manual → klik Print.
   ± 15 detik per resi. Besok-besok printer tersambung sendiri.

───────────── FITUR ─────────────
• Cetak dari HP saja, tanpa install APK — cukup browser (web app)
• Bisa di-install ke layar utama (PWA) dan tetap jalan saat koneksi putus
• Semua merek printer thermal Bluetooth: Xprinter, Goojprt, Zjiang, HPRT,
  Rongta, Phomemo, Peripage, Sinmark, MTP-II, HM-A300, Eboss, Zicox, Cat Printer,

• Ruang gunting otomatis di bawah tiap resi (Ketat/Sedang/Longgar) → potong rapi
• Rangkap/gandakan cetak dalam satu kali klik
• Mode Input Manual: ketik nama toko, pengirim, penerima, alamat, kurir, no. resi,

───────────── HASIL CETAK ─────────────

2. Setelah pembayaran berhasil, chat penjual (maks. ± … jam) untuk klaim kode.

───────────── SPESIFIKASI ─────────────
• Platform : Web (Chrome / Edge terbaru di Android & desktop)

bukan BLE. Cek dulu merek & tipe printer Anda via chat sebelum order.

## 8. Pengingat Operasional untuk Penjual (jangan dipajang ke pembeli)

1. Setiap pengiriman kode: catat di file `licenses/kode-<tanggal>.txt` — tandai mana yang sudah terjual agar tidak dobel kirim.
2. Marketplace punya aturan produk digital: kalau kategori ditolak, jual sebagai "akses/panduan digital" atau kirim kode lewat chat setelah order barang fisik pendamping (mis. stiker/kertas thermal).
3. Kirim kode lewat chat/invoice, jangan taruh link aplikasi + kode di kolom komentar publik — gampang disalahgunakan.
4. Kalau ada kode bocor/beredar: jalankan `node scripts/gen-licenses.mjs <jumlah>` tanpa kode itu, ganti `LICENSE_HASHES`, deploy ulang — aksesnya langsung hangus.
